# StudyTask - Student To-Do App

A React + Vite student task management UI inspired by the supplied design.

## Features

- Dashboard
- Add tasks
- Mark tasks completed
- Delete tasks
- Search tasks
- All / Pending / Completed filters
- Task statistics
- Progress bar
- Subject donut chart
- Dark mode
- Responsive layout

## Important

This version does **not** use a backend or localStorage.

Tasks are stored only in React state, so refreshing the browser resets the task list.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
